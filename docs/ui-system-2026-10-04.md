# Aimail 统一工作区设计

2026-10-09 最终组件方案已确定：[ADR 0013](adr/0013-unified-owned-ui-components.md)。
全站采用自有组件 + Radix + Tailwind，Lucide 图标，沿用当前收件箱视觉基线。
Ant Design 逐页迁出；本文件描述的共享主题适配是过渡状态，页面迁移尚未完成。

这次调整直接应用于生产收件箱、线索、跟进、开发信和组件页。公开邮箱产品提供的信息层级和布局启发不等于它们的内部实现；Aimail 不移植其品牌、私有 API 或未经核验的 UI 代码。

统一的设计由中央令牌和共享组件表达，而不是各页面分别选颜色。

- 字体：自托管 Inter / Noto Sans SC；正文 14px，邮件原文 15px、行高 1.8；辅助信息 12px，栏标题 16px，页面标题 20px。
- 空间：4/8px 间距节奏；导航、列表、阅读区和客户区分别有明确边界与自己的滚动区域。只对需要独立操作的内容使用容器，普通文字不再层层包卡片。
- 颜色：冷白表面、石板灰文字，靛蓝作为唯一常规操作与选中强调；警告和失败色仅表达真实状态。亮暗模式遵循同一语义令牌。
- 图标：Lucide，常用 16/18px、线宽 1.75；图标与文本共同对齐，装饰图标不替代操作名称。组件库内置交互图标由其组件管理。
- 组件：控件圆角 8px、面板圆角 12px；表单、按钮和菜单复用自有组件。现存 Ant Design 控件在迁出前继续读取共享字体、颜色及尺度。

收件箱支持只显示标题的简洁模式以及包含发件人、标题和摘要的概括模式。买卖邮件有清晰的 SALES LEAD 标记，普通邮件使用内容类型。联系人聚拢是可选操作，相同地址的独立交易话题不会合并成一个需求。

右侧客户工作区保持独立，阅读旧邮件、回复或滚动正文不会改变最新累计需求。
工作区按当前话题展示客户资料和截至最新邮件的统一生意概况；不在右侧重复原文入口、
时间线与单封读数。来源引用保留在快照中，模型、任务版本、更新时间与实际覆盖仍可见。
旧结果、截断与失败明确显示。手机使用可关闭的客户抽屉。

导航、邮件列表、客户工作区的宽度可拖动并保存。正文自动占据剩余宽度，
不再受 800px 内容上限限制；客户栏可收起恢复，“专注正文”临时收起所有辅助栏，
退出后恢复原来布局。窄屏按实际空间收缩，保持阅读区可用。

正文每封邮件可按需翻译为中文，并切换原文、中文、对照。原文不会被改写；
对照在宽正文中并排、在窄正文中上下排列。翻译只覆盖本封新增正文，历史引用和附件保持原样。
翻译成功后按原文内容与任务版本复用，切换模型不重算，保留实际生成模型署名。

设计验收包括真实 API 配合合成邮件的布局、联系人分组、搜索、列表密度、左右栏操作、摘要来源链接、草稿保持及移动宽度；合成数据不代表生产模型准确率，也不代表服务器已部署。
