# 原始 PDF 附件预览（2026-10-09，m5）

## 用户反馈与原因

用户在线程 316 / 邮件 417 看到中英对照左栏内部滚动条，以及 PDF 点击后无法正常查看。
内层滚动条属于原始 HTML iframe，上一阶段 PR #78 已让 iframe 完整增高、由整封邮件统一滚动。
附件按钮原先只调用文字提取接口，没有原件读取、PDF 预览或下载功能。

## 实现与约定

- 新增同邮箱、同登录授权范围的原始附件读取接口；404 隔离其他邮箱附件，文件字节保持不变。
- 实际 PDF 作为 application/pdf 预览；其他文件按 octet-stream 下载，文件名 UTF-8 编码并移除路径，不信任来信的 MIME 类型。
- 附件点击先打开原件窗口，PDF 使用浏览器阅读器显示，并始终提供下载原件；提取文字是独立可选视图。
- 扫描件、未提取文字的附件也可打开原件。加载失败显示重试；关闭、切换、离开页面释放 Blob URL，取消在途结果。
- 请求保持点击时的邮箱作用域，20 秒读取期限涵盖完整二进制响应；不调用模型、不改写附件。

## 验证与入口

API 测试覆盖原始字节、登录、跨邮箱 404、文件名及伪装 HTML 不内嵌；前端覆盖扫描 PDF、下载、关闭与在途取消、邮箱作用域。
完整 precommit、正式发布与生产核验见 PR / infra 的 aimail-reader-controls-production-2026-10-09.md。
