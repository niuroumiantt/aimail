# 邮件操作归属、滚动条与翻译连接（2026-10-09，m5）

## 用户要求

回复、删除、AI 阅读、分配属于当前打开邮件，放进正文框；模型选择收成图标菜单。
“专注正文”改为“邮件全屏”，客户工作区入口更明显，滚动条减弱。保留原文内容与既定组件路线。

## 实现

- 当前邮件操作和阅读布局控制固定在正文卡片顶部；整页命令栏移除。
- 同步属于邮箱，移到列表标题旁；模型图标位于顶栏，展开显示当前型号、连接状态与选择。
- 客户工作区按钮保持可见，以底色和“已展开／已收起”明确状态；从全屏打开客户区会恢复布局。
- 邮件全屏保留全部当前邮件操作；AI 阅读仍可打开。回复后滚到本封会话的编辑区。
- 正文、客户区、列表统一细、低对比滚动条；原始 HTML iframe 自动完整增高，由外层阅读区滚动。
  去掉 30000px 高度截断，增加小数测量余量；长邮件不产生内部滚动条。
- 窄正文栏的发件人、时间和翻译工具分行，避免挤成竖排。
- 翻译连接失败只显示预先定义的安全提示，明确引导至顶栏模型图标；仍不暴露上游异常。
