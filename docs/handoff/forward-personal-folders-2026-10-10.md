# 邮件转发与个人文件夹（2026-10-10，m5）

## 目标与已定规则

用户要求增加邮件转发和最多三层自建文件夹，已选择“个人文件夹，各人独立、设备间同步”。
沿用已授权的 Git 推送、合并、正式发布流程。文件夹保存于 Aimail 服务器，按可信登录邮箱
身份和被查看邮箱隔离；电脑、iPad、手机登录同一账号可读取。不会创建或移动网易 IMAP
文件夹，不改变原邮件、回收站或销售进度；本轮不增加离线文件夹界面。

## 实现

- 当前邮件工具栏增加“转发”“移动”。转发默认选择会话最新一封，可改选具体邮件，
  收件人留空由人填写；允许补充说明、改主题、选择是否包含独立附件。
- 服务端从保存的原始 MIME 生成转发，保留 HTML 表格、内嵌 CID 图片和附件字节，
  不调用模型。只用已授权个人 SMTP；sales@glocalstorage.com 仍为只收地址。
  一次性令牌、负责人检查和不确定发送锁继续生效。转发独立建线程，不伪装为原会话回复，
  不将原会话标成已回复。forward_attempt 记录来源，人工核对兼容转发。
- 导航增加可展开树、三级各缩进 12px、长名省略及完整路径提示；加号新建、行末菜单
  新建子文件夹/重命名/删除空文件夹。第三级不允许再创建子级，服务端同样强制限制。
- “移动”整理整条会话，也可移出自建文件夹。文件夹同层名称经 NFKC/大小写规范化去重；
  有子文件夹或邮件时不能删除。原文与附件不可变约束保持。
- 模拟环境与真接口保持同一数据接口，切邮箱/切用户的在途请求不污染新作用域。
