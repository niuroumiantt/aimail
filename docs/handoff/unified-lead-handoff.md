# Leadsgen 交接通知与现有交接桥接

2026-09-27，配套 leadsgen 的 unified-lead-handoff 分支。

新增受现有集成令牌保护的交接状态导出、接受/退回与内部通知接口。共享邮箱权限不扩展给员工；只有相应线程的待接手人能决定，原邮件附件仅从共享线程读取。发件人限定具备共享邮箱权限的管理员个人账号，收件人限定配置内员工。

通知包含摘要、接受/退回链接与 .eml 原件。通知账本以线索及版本为幂等键，发送前持久化。SMTP 不确定或进程中断后标记 unknown，不自动重发。GET、邮件预览不改变交接状态。

新 Aimail 交接事件显式请求通知；历史事件默认不请求。Leadsgen 同步后把新事件纳入通知队列并使用对应线索链接。部署顺序为 Aimail 然后 Leadsgen；两端先备份数据库。既有交接不补发邮件。

验证：完整 Python 测试及 Ruff；通知测试使用假发件器验证收件人白名单、重复调用、HTML 转义、SMTP 不确定结果与嵌套附件保留。集成测试验证跨邮箱访问拒绝、状态版本冲突和退回原因。未发送真实邮件。生产员工收件及确认尚需部署后的真人验收。

## 生产来源修正
生产主邮箱为 Larry，SHARED_MAILBOX 为 sales@，两者不能用同一个默认 mailbox_id 代替。启动时显式传入共享邮箱 ID；机器线索和交接接口仅合并这两个配置来源。其他员工私人邮箱排除，即使存在同名成员也不扩大读取范围。已明确的交接仍按负责人/待接手人决定。

扩大到正确来源后，需要在 Leadsgen 停止工作进程、备份数据库后重置 aimail_lead_since / aimail_lead_after 游标并恢复服务，让较早确认的 sales@ 线索重新被幂等读取。不得删除账户、交接或原邮件。新增三邮箱测试验证分页合并与私人邮箱排除。
