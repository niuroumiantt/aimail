# 结构化译文与公司身份查重

翻译只替换安全邮件树中的文本节点。表格行列、合并单元格、列表、链接及图片引用由确定性代码保留，模型不生成 HTML。逐节点核对编号和数字，缺项、重复项或新增项均失败；无法确定本封与历史边界时保留纯文本翻译，原文始终可读。任务升级为 translate_mail@2；带有相同原文校验值的旧版译文仍可直接读取，并提示重新翻译可保留表格。只有显式重新翻译才强制调用模型。

客户建档只呈现公司和联系人资料。既有交易字段保留在来源事项，不进入公司主档。联系人默认取实际通信对象；正文未明确官网时，企业邮箱域名仅作为待核实预填，公共邮箱不推断官网。

Leadsgen 是公司身份的权威库。通过现有受令牌保护的适配器推送只读身份目录到 Aimail，Aimail 不主动依赖下游。建档前按企业邮箱、注册域名及规范化公司名查询；名称只能提示，不能单独自动合并。跨域或多个匹配必须人工核实。保存前强制重新检查，Leadsgen 在写事务内再检查，单一企业身份沿用稳定 company_id。每次来信事项、原始人工确认记录和回执保持独立。

验收覆盖表格/合并单元格、数字错位、恶意 HTML、历史边界、旧缓存、企业名后缀变化、跨邮箱同域、公共邮箱、域名冲突、同步重试与旧协议。

本机同步使用可撤销的专用只读设备授权，每次导出重新检查所属用户的现有邮箱权限。M5 通过私人 SSH 通道增量下载 Aimail 已接收的完整 RFC822、附件及带来源署名的译文。原件和附件逐文件校验 SHA256，游标只在完整一批落盘后推进，失败可续传。数据在 ~/.local/share/aimail/local-mail/，配置和文件仅当前系统用户可读；日志在 ~/.local/state/aimail/local-mail/。云端隐藏或删除不自动删除本机副本；本机整理也不反向改动原件。后续分析可直接读取本机 SQLite 与原始文件。本阶段不声称补齐尚未被 Aimail 接收的网易历史邮件，也不提供离线浏览器界面。
