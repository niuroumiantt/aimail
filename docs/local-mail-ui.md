# 真实邮箱本地只读试点

入口：http://127.0.0.1:5197/mail。设计样本仍在 `/design`，不混入真实列表。

前端采用 Ant Design 6.6.4 的按需组件：按钮、输入、筛选选择器、表格、
折叠、抽屉、描述列表、状态与加载反馈。主题集中在 `web/src/tokens/mail-theme.ts`，
默认紧凑模式，支持明暗切换。没有引入 Ant Design Pro 或其他后台脚手架。
真实邮箱页面独立按路由加载，旧页面不预载其组件包。
2026-09-20 初次构建邮箱独立 JS 约 219 KB gzip、CSS 约 2.6 KB gzip；
这不是完整首屏体积，首屏还包含共享应用资源。后续以实际构建结果为准。

支持搜索已收取的发件人/标题/摘要、分析状态筛选、时间排序、
列表拖拽调宽与隐藏恢复、专题区折叠、邮件往来切换、服务范围抽屉。
不将「未分析」标成「未读」，不将本地邮件数量当作网易全邮箱数量。
为通过既有依赖发布冷却期检查，锁文件中的 lru-cache 从 11.5.3 调整至
经 registry 校验完整性的 11.5.2；未关闭供应链策略。

启动（仓库根目录）：`uv run python -m aimail.local_web`。
前端在 web 目录用 `npm run dev -- --port 5197` 启动；8910 为只监听本机的试点后端。
依赖独立的 openapi 网关 http://127.0.0.1:8800；其后台可查看调用内容和实际 token。

运行数据：`~/.local/share/aimail/pilot/mailbox.sqlite3`。
网关凭据：`~/.config/aimail/local-api.env`，权限必须为 0600。
收信配置复用 OA 的 `~/.local/state/oa/sales-leads-preview/mailbox.env`，不改 OA 项目。

手动同步仅取 INBOX 最近 30 天最新 30 封，单封最大 2 MB，重复跳过。
不发送、不删除、不修改远端已读状态。不在进入页面时调用模型。
分析按钮只处理当前话题最新来信；不是完整话题或全邮箱综合分析。
内容、附件及数字仍需人工核对。网易全量语义搜索、员工登录与完整操作审计尚未接入。
本服务不得直接绑定公网，不是生产多用户服务。

## 问邮箱

真实页右上角「问邮箱」打开跨话题侧栏，与左侧选中邮件无关。
每次按时间倒序提供最多 60 封本地原文，每封最多 3000 字符，总正文预算约
48000 字符，不读附件；回答显示纳入数量与截断数量，不声称检索全部网易邮箱。
模型结论附 source_id 和原文摘录，代码验证引用存在且摘录匹配；数字不匹配则警告。
这不是语义正确性的保证，答案需人工核对。点击引用定位具体话题和邮件。

提问与回答经过既有独立 API 网关，token、耗时与输入输出沿用网关记录。
本地数据库 assistant_event 表追加记录问题、回答、失败、清屏，禁止更新和删除。
清屏只改变当前可见历史，不抹除记录；清屏后下一次提问不携带此前上下文。
任务运行时拒绝清屏和重复任务，刷新页面可恢复可见对话。服务重启会将未完成记录
标为中断。当前审计身份是 local-user，并非已验证的员工身份。

验证：`uv run python evals/ask_mailbox/run.py` 检查引用合同；配置本机网关后加
`--live` 运行询价/推广区分、无依据、邮件指令注入三个合成样例。
2026-09-20 本机 27B 三例通过。这是小规模冒烟基线，不代表复杂业务问答准确率。
后端测试覆盖虚构引用拒绝、数字警告、跨话题输入、清屏保留原文与审计、并发拒绝；
前端测试覆盖真实回答恢复、精确原文引用回调和不绑定当前选中邮件的提交合同。
