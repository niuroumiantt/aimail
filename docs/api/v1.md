# 下游接口 v1

给 OA、PO、合同这类系统接的口。只出**人确认过的事实**(线索表),模型的建议永远不出门。
形状钉死在 `server/tests/test_downstream.py` 的 `LEAD_V1_KEYS`:改任何字段先写 ADR,再改那张键表。

## 身份

机器用令牌:`Authorization: Bearer <令牌>`。令牌在部署机的环境变量 `API_TOKENS` 里,格式 `名字:令牌,名字:令牌`,
每个至少 16 字符(`openssl rand -hex 32`)。机器**只能读**:拿令牌去调 `/api/*` 里写线索的接口一律 401——
确认线索、改状态只有人能做(宪法第五条)。

## GET /v1/leads

| 参数 | 说明 |
| --- | --- |
| `since` | 上一页的 `next_since`(ISO 8601);空 = 从头 |
| `after` | 上一页的 `next_after`(线索 id);和 `since` 一起构成游标,同一秒里确认的几条靠它接着翻,一条不漏 |
| `status` | `quote` / `quoted` / `following` / `won` / `lost`;不填 = 全部 |
| `limit` | 默认 200,最多 1000 |

按 `(updated_at, id)` 升序。响应:

```json
{
  "version": "v1",
  "leads": [ { "version": "lead@1", "...": "见下表" } ],
  "next_since": "2026-09-19T08:14:02+00:00",
  "next_after": 12
}
```

`lead@1` 的字段:

| 字段 | 含义 |
| --- | --- |
| `version` | 永远 `lead@1`;字段变了就是 `lead@2` |
| `id` | 线索 id,字符串;同一条线索每次变化 id 不变 |
| `status` | `quote` 待报价 / `quoted` 已报价 / `following` 跟进中 / `won` 成交 / `lost` 丢单 |
| `company` `contact` `email` | 公司、联系人、对方邮箱(来自线程) |
| `wants` `quantity` `region` | 要什么、多少、地区——人确认时可以改过 |
| `next_step` | 业务员写的下一步 |
| `confirmed_by` `confirmed_at` | 谁、什么时候把建议确认成事实 |
| `updated_at` | 最后一次变化;游标用它 |
| `source` | `{ mailbox, thread_id, subject }`:从哪个邮箱、哪条线程来 |

`GET /v1/leads.csv` 同样的内容一行一条,Excel 直接开(带 BOM)。界面上的「导出 CSV」走同一份。

## Webhook

配了 `WEBHOOK_URL` 与 `WEBHOOK_SECRET`(两个都要),线索每次变化(`lead.confirmed`、`lead.updated`)都会
POST 一次,JSON 正文:

```json
{ "event": "lead.confirmed", "delivery": "42", "created_at": "…", "lead": { "version": "lead@1", "...": "同上" } }
```

请求头:`X-Mail2leads-Event`、`X-Mail2leads-Delivery`(投递 id,重试时不变——下游按它去重)、
`X-Mail2leads-Signature: sha256=<hex>`(HMAC-SHA256,密钥是 `WEBHOOK_SECRET`,签的是原始正文字节)。

下游验签(Python):

```python
import hashlib, hmac

expected = "sha256=" + hmac.new(secret.encode(), body, hashlib.sha256).hexdigest()
ok = hmac.compare_digest(expected, request.headers.get("X-Mail2leads-Signature", ""))
```

2xx 算送到;其余(含网络错误)记下原因,按 1 分钟、5 分钟、30 分钟、2 小时、12 小时、之后每天重试,永不丢。
送没送到在 `GET /api/outbox` 和线索页右上角看得见。`python -m aimail deliver` 手动推一次。
